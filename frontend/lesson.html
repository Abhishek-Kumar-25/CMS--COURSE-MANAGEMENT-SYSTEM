Function Basics

A function is a reusable block of code designed to perform a specific task. Functions are the building blocks of readable, maintainable, and reusable code.

JavaScript 
function greet(name) {
    return "Hello, " + name + "!";
}

// Function call
const message = greet("John");
console.log(message); // "Hello, John!"
Pro Tip

Always use descriptive function names. A good function name tells you exactly what the function does.
